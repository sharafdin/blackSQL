# blackSQL (Legacy – Python)

This folder contains the **original Python implementation** of blackSQL. The project is being rewritten in Rust; the new implementation will live at the repository root.

## Run the legacy scanner

From this directory:

```bash
pip install -r requirements.txt
python blacksql.py -u "http://example.com/page.php?id=1"
```

See the main [README](../README.md) for full usage and options.
